# Advanced Persistent Threats (APT) Research Project

An interactive website exploring Advanced Persistent Threats in cybersecurity. This project provides information about various APT groups, their tactics, and their impact on global cybersecurity.

## 🌐 Live Demo

Visit the live website: [APT Research Project](https://darelbriones13.github.io/AdvancePersistentThreats/)

## ✨ Features

- Interactive UI with matrix rain animation
- Real-time typing effects
- System breach simulation
- Dark/Light theme toggle
- Responsive design
- Interactive sound effects
- Detailed APT group information

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Audio API
- Intersection Observer API

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/DarelBriones13/AdvancePersistentThreats.git
   ```

2. Open `index.html` in your web browser
